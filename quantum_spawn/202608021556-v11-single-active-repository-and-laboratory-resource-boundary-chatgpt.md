# 6. 300-second operator protocol

All future V11 work uses supervised operator sessions of no more than 300 seconds.

An operator session:

- starts from an authenticated V11 head;
- declares one narrow objective;
- may inspect the laboratory as a read-only resource;
- changes only V11;
- hard-stops at or before 300 seconds;
- reports completed work, incomplete work, changed files, tests, CI state, failures and next action;
- waits for Product Owner review before another launch.

An operator session is not automatically a final BUILD PASS or TEST PASS.

V11 may require multiple operator sessions to complete one coherent build unit.

The Product Owner uses the command `execute` or another explicit launch instruction to authorise the next session.
