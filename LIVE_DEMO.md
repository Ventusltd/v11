# V11 Live Solar DC Simulator

The V11 integrated workbench is a public engineering prototype for the 24-string reference inverter block.

## Preferred GitHub Pages URL

https://ventusltd.github.io/v11/

The `V11 Live Simulator` workflow enables, deploys and verifies this endpoint when repository Pages settings permit workflow deployment.

## Stable public fallback

https://raw.githack.com/Ventusltd/v11/v11-live-demo/browser/workbench.html

The release branch is updated only after the live workflow and engineering acceptance path have been prepared. The workflow independently verifies the exact-commit rawcdn URL and uploads a `v11-live-fallback-<run_id>` evidence artefact containing the tested SHA and immutable URL.

## Engineering status

This is a research and engineering prototype, not a certified project-design output. Module, conductor, connector, inverter and route assumptions remain provisional unless separately evidenced. Geometry-derived route length, loop-area and travelling-wave outputs must not be treated as construction, procurement or compliance approval.
